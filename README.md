# Telegram Notifier Homebrew tap

Official Homebrew tap for the [AgentForge Telegram Notifier standalone CLI](https://github.com/AgentForge-Labs/telegram-notifier-distributions).

## Install

```bash
brew tap AgentForge-Labs/telegram-notifier
brew install telegram-notifier
telegram-notifier version
```

The formula downloads version 0.1.0 from the public GitHub Release using verified SHA-256 sums for macOS and Linux, amd64 and arm64. This is an independent tap (not a Homebrew/homebrew-core submission). A real Homebrew installation on both macOS and Linux should be separately verified before claiming all platforms tested.
